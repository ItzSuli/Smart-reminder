# Downloads

`SmartReminder.apk` is the ready-to-install app. On your phone:

1. Open this file on GitHub and tap **Download** (or **View raw**).
2. Open the downloaded file. Android asks to allow installs from your browser – allow it once.
3. Install, open the app, and follow the **Finish setup** card.

Every new APK here is signed with the same key, so installing a newer one simply updates the app.
